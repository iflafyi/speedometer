# GPS Спідометр

Веб-спідометр для машини на основі GPS телефона.

**Відкрити:** https://iflafyi.github.io/speedometer/

- Швидкість km/h або mph, аналогова шкала
- Макс., середня, дистанція, час, висота
- Заміри 0–100
- Ліміт швидкості зі звуковим сигналом
- HUD-режим для відображення на лобовому склі
- Карта маршруту з кольором за швидкістю
- Датчик руху: акселерометр телефона між точками GPS зменшує затримку (телефон у тримачі, калібрується сам)
- Демо-режим
- Встановлюється як застосунок (PWA): іконка на головному екрані, повний екран, працює без інтернету
