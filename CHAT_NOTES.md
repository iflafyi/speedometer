# Нотатки для продовження роботи (контекст чатів з Claude)

Цей файл — короткий підсумок попередніх чатів, щоб у новому чаті одразу продовжити.
**Новий чат:** скажи Claude «прочитай CHAT_NOTES.md у репозиторії iflafyi/speedometer».

## Проєкт
- GPS-спідометр для машини, веб-застосунок (PWA).
- Репозиторій: https://github.com/iflafyi/speedometer
- Сайт (GitHub Pages, гілка `main`): https://iflafyi.github.io/speedometer/
- Телефон: **Samsung Galaxy M12** (акселерометр є, **гіроскопа немає**), стоїть у тримачі в машині, браузер Chrome.
- Мова інтерфейсу — українська.

## Файли
- `index.html` — увесь застосунок (HTML + CSS + JS в одному файлі). Розділи JS позначені коментарями `// ---------- назва ----------`:
  route track · units · gauge · prediction between GPS fixes · motion sensor (accelerometer) fusion ·
  animation loop · GPS · demo · extras (wake lock, beep, знак ліміту) · route map · wiring · install as an app (PWA)
- `sw.js` — service worker (офлайн-кеш). **Після будь-якої зміни файлів застосунку піднімати `VERSION`** (зараз `v6`), інакше телефон показує стару версію.
- `manifest.webmanifest`, `icons/` — для встановлення як застосунок.
- `README.md` — опис функцій.

## Що вже зроблено (по комітах)
1. `3776cfc` — базовий спідометр: km/h / mph, аналогова шкала, макс./середня/дистанція/час/висота, заміри 0–100, ліміт швидкості зі звуком, HUD-режим (дзеркально для лобового скла), демо-режим.
2. `a91fad3` — карта маршруту (Leaflet), колір лінії за швидкістю.
3. `4720ef2` — PWA: іконка на головному екрані, повний екран, офлайн.
4. `70cb796` — менше затримки: прогноз швидкості між точками GPS, плавна анімація незалежна від FPS (швидша анімація стрілки).
5. `8df467a` — кнопка «Датчик руху»: акселерометр між точками GPS зменшує затримку; телефон у тримачі, автокалібрування (без гіроскопа).
6. `859cdd5` — екран не згасає весь час, поки сайт відкритий (Screen Wake Lock; автоматично відновлюється після згортання/блокування, торкання, кожні 15 с). Примітка: режим енергозбереження Samsung може це блокувати.
7. Фікс «екран все одно гасне»: запасний спосіб — невидиме зациклене відео `keepawake.mp4` (muted, 64×64, ~4 КБ) грає поруч із Wake Lock; у шапці значок ☀ (ON = Wake Lock, ВІДЕО = лише запасний, OFF = нічого не працює), натискання показує причину помилки.
8. Користувач насправді у **Opera** (Android): Wake Lock → `NotAllowedError`. Відео-запаска після першого дотику грає без muted з гучністю 0.01 (доріжка — тиша), бо Chromium тримає екран лише для відео зі звуком; відео на весь екран з opacity .01. Рекомендовано відкривати в Chrome.
